# Homepage and shared design review

The owner requested a professional redesign of the existing site and direct integration of the 50-tool platform into its homepage. This is an upgrade to the current site; existing URLs and content remain.

Official sites reviewed on 2 November 2026:

- https://www.ilovepdf.com/ — prominent task categories, short tool descriptions and immediate access to common document actions.
- https://smallpdf.com/ — a clear main promise, focused popular tools, grouped navigation and explanations of processing/privacy.
- https://www.futurepedia.io/ — AI discovery and educational content, with links to categorized tool discovery.

The review informed the following design choices; these are our own implementation decisions, not claims of equivalence or superiority:

1. Make the existing homepage the primary entry point for free utilities.
2. Use task search, five categories and eight varied starting tools, with all 50 available on demand.
3. Open a lazy-loaded working tool directly within the homepage; retain existing individual URLs for links, accessibility fallbacks and search indexing.
4. Share recent/favorite preferences with the existing module, without storing file contents.
5. Protect unfinished work before switching, and provide privacy, guidance and limits beside the workspace.
6. Keep original rankings, Klap placement, AI playground, products, blogs, authentication and ad/consent scripts.
7. Apply restrained shared styling across the existing public pages while retaining the user's light/dark preference.

No claim that the site is objectively the best on Google, no fabricated usage numbers, reviews, certifications or testimonials, and no new paid provider or subscription.
