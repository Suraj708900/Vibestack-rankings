Firebase

Ranked #2 in Databases & backends

Verdict

Google's mature backend with great mobile SDKs. NoSQL data model takes some getting used to.

Pricing: Free Spark plan; pay-as-you-go (always check the official pricing page)

free-tier

Visit Firebase ↗

Alternatives

  • Supabase: Postgres plus auth, storage and realtime. The default backend for vibe-coded apps.
  • Neon: Serverless Postgres with branching. Ideal when you just need a database, not a full backend.
  • Convex: Reactive TypeScript backend that AI agents write well. Great for realtime apps.
