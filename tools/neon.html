Neon

Ranked #3 in Databases & backends

Verdict

Serverless Postgres with branching. Ideal when you just need a database, not a full backend.

Pricing: Free tier; see site (always check the official pricing page)

postgresfree-tier

Visit Neon ↗

Alternatives

  • Supabase: Postgres plus auth, storage and realtime. The default backend for vibe-coded apps.
  • Firebase: Google's mature backend with great mobile SDKs. NoSQL data model takes some getting used to.
  • Convex: Reactive TypeScript backend that AI agents write well. Great for realtime apps.
